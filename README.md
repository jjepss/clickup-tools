# clickup-tools

Monorepo of ClickUp tools and integrations. Each tool lives in its own directory.

## Tools

| Tool | What it does |
|------|--------------|
| [`clickup-logger/`](clickup-logger/) | Your own ClickUp activity log. A tiny Cloudflare Worker that records workspace events (status changes, and more if you want) with full attribution — the audit-log superpower, without the Enterprise plan. |
